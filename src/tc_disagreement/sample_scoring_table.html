Table 3: Precision, Recall, F1 Score

Treating each file as a binary classification: does the checker correctly identify files with proven bugs?

True Positive = checker reported error AND proven bug exists
False Positive = checker reported error BUT no proven bug exists
False Negative = checker reported nothing BUT proven bug exists

Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
F1 = 2 × Precision × Recall / (Precision + Recall)

In this sample data, all 8 files have at least one proven bug across tiers. We assume checkers report errors on the following counts:
